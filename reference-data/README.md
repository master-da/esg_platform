# Reference data

Global reference data: controlled lists, units, geographies, the factor-code taxonomy, emission
factors, FX rates and terminal configurations. It is kept separate from customer data (PRD design
principle 5). `make refdata` loads it in `manifest.json` order. Every upsert is audited with source
`refdata-loader`.

**No fabricated values.** Every number in `lib/` comes from a published source cited on its row.
A taxonomy leaf with no cited factor has no factor row. Calculations against it show **UNKNOWN**
until a library editor adds and activates a cited factor. All seeded factors are marked
`advisor_reviewed = false` until the domain advisor confirms them.

## How the factor files are built

`lib/emission_factors.csv` and `lib/factor_conversions.csv` are generated. Do not edit them by hand:

```bash
# download the three pinned files listed above into an empty directory, then:
python -I reference-data/sources/build_factors.py \
  --desnz2025 <dir>/ghg-conversion-factors-2025-flat-format.xlsx \
  --desnz2026 <dir>/ghg-conversion-factors-2026-flat-format-revised.xlsx \
  --epa <dir>/SupplyChainGHGEmissionFactors_v1.3.0_NAICS_CO2e_USD2022.csv
```

- `sources/factor_map.csv` maps each taxonomy leaf to its source row. The script fails if a mapped
  row is missing. It records the DESNZ row ID, and it follows renamed rows across releases by their
  stable ID.
- **Conversions** (e.g. tonnes → litres, kWh → litres) are the ratio of the *same fuel's* published
  factors in the two units. A converted calculation therefore reproduces DESNZ's published factor
  for the entered unit exactly.
- **Geography.** DESNZ factors are stored as `GLOBAL` defaults, with the UK origin stated in
  `quality_rating`. The Bangladesh grid factor is `BD`. Resolution falls back from country to
  region to global.
- **Validity.** DESNZ factors are valid for their reporting calendar year. The Bangladesh GEF uses
  the Bangladesh fiscal year (July–June). No official GEF is published after June 2022, so later
  electricity calculations show UNKNOWN. Extending a factor to later periods is an explicit,
  audited library decision.
- **Spend factors** carry a provisional applicability window (2022–2026), pending advisor sign-off.
  BDT spend is converted at the cited annual FX rate, without inflation adjustment to 2022 USD.
  This is listed as a limitation.

## Taxonomy

`lib/taxonomy_nodes.csv` is generated by `sources/build_taxonomy.py`. Codes follow the PRD's
14-digit example: Stationary combustion `01010000000000` › Non-renewable `01010000001000` ›
Liquid `01010000001200` › Petrol `01010000001201`. The final digit scheme is an open PRD item.
Codes never reach client-facing APIs. Clients see only `ref.taxonomy_labels` (description paths).

Every requirement carries its regulator, law, source URL and effective date (all `NOT NULL`).
Applicability is a JSON condition evaluated by the engine. A requirement that applies to everyone must
say so explicitly (`applies_universally`). An empty condition never matches by accident.
